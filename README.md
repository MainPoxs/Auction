# 🏷️ Online Auction — Онлайн-аукцион

Веб-приложение для проведения онлайн-аукционов, разработанное на ASP.NET MVC.

## 📋 Описание

Платформа позволяет пользователям выставлять лоты на аукцион, делать ставки и отслеживать статус торгов в реальном времени.

## 🛠️ Технологии

- **Backend:** C#, ASP.NET Core MVC
- **Frontend:** Razor Views, HTML5, CSS3, JavaScript
- **База данных:** PostgreSQL / Entity Framework
- **Аутентификация:** ASP.NET Identity
- **Прочее:** SignalR (WebSockets)

## ✨ Функционал

### Для пользователей:
- Регистрация и авторизация
- Просмотр каталога аукционов
- Участие в торгах
- Отслеживание своих ставок
- Личный кабинет с историей торгов

### Для продавцов:
- Создание аукционов с указанием начальной цены
- Загрузка фотографий лотов
- Управление активными лотами
- Просмотр истории продаж

### Для администратора:
- Управление пользователями
- Модерация лотов
- Статистика по аукционам
